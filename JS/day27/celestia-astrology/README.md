# Celestia Astrology Website

A responsive, frontend-only astrology-themed website built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open the `celestia-astrology` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Features
- Responsive cosmic-themed landing page
- First name, last name, day, month and year form
- Date validation (including leap years)
- Sun-sign zodiac calculator
- Zodiac profile cards
- Daily reflection selector
- No framework, backend, API key or installation required

## Important
The readings are illustrative entertainment content based on common Western sun-sign date ranges. They are not scientific predictions or professional advice. The daily reflections are locally generated from a small set of sample messages; they are not live astronomical forecasts.

## Files
- `index.html` — page structure
- `style.css` — layout, theme, responsive styling and animations
- `script.js` — zodiac data, form validation and interactions
